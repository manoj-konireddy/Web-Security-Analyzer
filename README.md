# 🛡️ Web Security Analyzer

A Flask-based web application that analyzes the security posture of a website and generates detailed security reports in PDF and JSON formats.

---

## 📌 Features

- 🌐 Website Information
- 🛡️ Security Headers Analysis
- 🔒 SSL Certificate Validation
- 🍪 Cookie Security Analysis
- 🌐 HTTP Methods Detection
- 🤖 robots.txt Checker
- 📄 security.txt Checker
- 📊 Risk Score Calculation
- 💡 Security Recommendations
- 📄 Professional PDF Report
- 📁 JSON Report Export
- 📱 Responsive User Interface
- ⚠️ User-Friendly Error Handling
- ⏳ Loading Animation During Scan

---

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Web-Security-Analyzer.git
```

Move into the project folder

```bash
cd Web-Security-Analyzer
```

Create virtual environment

```bash
python -m venv venv
```

Activate virtual environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
